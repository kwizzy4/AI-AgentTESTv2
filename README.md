# SteamPay — платёжная форма в стиле Steam

Демонстрационная клиентская платёжная система (HTML + CSS + чистый JavaScript, без библиотек).

## Структура
```
index.html      — страница оформления заказа и форма оплаты
css/style.css   — оформление в тёмных тонах Steam (#1b2838 / #66c0f4)
js/app.js       — маски ввода, валидация, превью карты, имитация шлюза
```

## Возможности
- Поля формы: **Фамилия, Имя, Отчество, e-mail, номер карты, срок действия (ММ/ГГ), CVC**;
- Маски ввода: номер карты группируется по 4 цифры, автослэш в сроке действия, только цифры в CVC;
- Валидация при потере фокуса и перед отправкой, включая **алгоритм Луна** для номера карты и проверку срока действия;
- Живое превью банковской карты с определением платёжной системы (Visa / Mastercard / МИР / AmEx);
- Корзина как в Steam: скидки, использование баланса кошелька Steam, выбор способа оплаты;
- Модальное окно статуса платежа (успех / отказ) — имитация работы эквайринга.

## Запуск
Просто откройте `index.html` в браузере, либо запустите локальный сервер:
```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Тестовые данные
- Номера карт, проходящие проверку Луна: `4276 1600 1234 5675` (Visa), `2202 2012 3456 7895` (МИР);
- Карта, оканчивающаяся на `0000`, демонстративно отклоняется «банком»;
- Срок действия должен быть больше текущей даты (например, `12/28`).

> ⚠️ Это учебный проект. Реальные платежи требуют PCI DSS, токенизации и платёжного провайдера
> (CloudPayments, ЮKassa и т.п.). CVC в реальных системах никогда не сохраняется.
